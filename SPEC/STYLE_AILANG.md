# AiLang Style Guide Reference

AiVectra does not own the AiLang authoring style contract.

The canonical AiLang style guide lives in:

```text
https://github.com/AiLangCore/AiLang/blob/develop/SPEC/STYLE_AILANG.md
```

AiVectra samples, templates, and AiLang source files must follow that canonical
guide. AiVectra-specific UI and rendering style rules live in:

```text
AiVectra/SPEC/STYLE_AIVECTRA.md
```

Do not duplicate AiLang style rules in this repository. Update the canonical
AiLang spec first, then update AiVectra code and docs to match.
